# Alert Monitoring SOP

## Objective
To provide a standardized procedure for SOC 1 Analysts to monitor and handle security alerts using the SIEM platform.

## Scope
This SOP applies to all inbound alerts generated by security tools (Wazuh, EDR, IDS/IPS) affecting systems relevant to financial reporting.

## Procedure

1. **Log in to SIEM Dashboard**
   - Verify time sync and data freshness.
   - Filter for alerts in the last 24 hours.

2. **Triage by Severity**
   - Critical: Immediate attention (e.g., RDP brute force, malware beaconing).
   - High: Within 2 hours.
   - Medium/Low: Logged for review.

3. **Analyze Alert Context**
   - Review source/destination IP.
   - Check user activity and endpoint behavior.
   - Cross-reference with firewall and EDR logs.

4. **Escalate or Close**
   - If actionable, assign to Incident Response.
   - Document in JIRA with alert ID and analysis summary.
   - If false positive, close with reason.
